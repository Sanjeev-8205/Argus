# Cadastre

A multi-phase AI system for document retrieval, reasoning, and policy validation.

## Project Phases

- **Phase 1**: Document Ingestion & Retrieval
- **Phase 2**: Hybrid Search (BM25 + Vector)
- **Phase 3**: Reranking
- **Phase 4**: FastAPI Backend
- **Phase 5**: LLM Agent with LangGraph
- **Phase 6**: Policy Engine
- **Phase 7**: Frontend UI
